人が最終確認する設計（HITL）。AI の出力は下書きです。AI抽出値には原文の根拠（年の補完は推定フラグ、人の追加入力は確認記録）が表示され、全項目を人が確認するまでダウンロードはサーバー側でロックされます。

Human-in-the-loop by design. AI output is a draft. AI-extracted values show their verbatim source (inferred years are flagged for review; reviewer-entered values are recorded as human attestations), and the download stays locked on the server until a person confirms every item.

  1. ①行政・大学・施設の指定様式は、罫線1本・結合セル1個の崩れで差し戻される。Official forms of municipalities, universities and facilities are sent back for a single broken border or split merged cell.
  2. ②文書を再生成する方式では、罫線・結合セル・定型文・用紙サイズが変わってしまうことがあります（画面の比較例は失敗を再現した模擬データです）。Methods that re-generate the document can alter borders, merged cells, boilerplate text and page setup (the comparison file is a simulated reproduction of those failures).
  3. ③Form-Guard は Word/Excel の対象 XML テキストノード置換・固定PDFの増分重ね書きを行い、21項目の決定論的検査（描画のずれ・セルのはみ出しを検出した場合は VIS-01 を追加）＋視覚 Diff＋原文ハイライト＋人間承認ゲートで指定欄以外の変更を検査します。Word / Excel 実機での表示・印刷と記入内容の最終確認は人が行います。固定PDFも同様です。Form-Guard replaces only target XML text nodes in Word/Excel (or writes an incremental overlay on fixed PDFs) and checks for any change outside the designated fields with 21 deterministic checks (plus VIS-01 if layout drift or overflow is detected), a visual diff, source highlighting and a human approval gate. Final display/print review in Word or Excel and fact sign-off stay with a person. Fixed PDFs follow the same review.

文書ごと作り直す方式では罫線・結合セル・定型文が変わることがあり、メモに無い数字が入ることもある。罫線1本・文言1つで差し戻しになるため、AIを安全に使えない。

Methods that re-create the whole document can change borders, merged cells and legal text, and can add numbers the notes never stated. One broken border or paraphrased clause means rejection — so they cannot use AI safely.

指定欄だけを XML バイト範囲（固定PDFは増分更新オーバーレイ）で書き換え、21項目の決定論的検査で指定欄以外の変更を検査。各値に原文の根拠を示し、人が確認するまでダウンロードをロックします。Word / Excel での表示と内容の最終確認は人が行います。固定PDFも同様です（年の補完は推定フラグ、人の追加入力は確認記録として区別します）。

It rewrites only the designated fields at the XML byte level (or via incremental-update overlay on fixed PDFs), checks for any change outside them with 21 deterministic checks, shows the verbatim source for AI-extracted values (flagging inferred years for review and recording reviewer entries as human attestations), and locks the download until a person signs off. The final review in Word / Excel / PDF and of the content stays with a person.

  1. スキャン欄と印刷ルール（字数・和暦・上限）を読む
  2. 対応付け・自己修正Claude（Haiku / Sonnet / Opus）またはオフライン、原文引用のみ
  3. 外科的な書き込みWord/Excelの対象XML置換・PDFの増分重ね書き
  4. 構造検査（21項目）ZIP・XML骨格・表・罫線・定型文・根拠
  5. 人による最終確認全項目を確認するとダウンロード解錠
