# 3分デモ動画 台本・絵コンテ（日本語ナレーション・175秒）

*Japanese narration script and storyboard for the 3-minute demo video of Form-Guard Agent (175 seconds, following the
web UI's guided tour `#tour=1` … `#tour=5`).*

Form-Guard Agent（Built with Claude: Japan 2026 提出作品）のデモ動画の台本と絵コンテです。

- **公式要件：デモ動画は日本語で作成（審査員は日本語話者）、長さは最大3分（180秒以内）。**
- 本台本は **175秒（2:55）** で終わり、5秒の余裕を残します。ナレーションは **標準版（空白除き925字・5.29字/秒＝毎分317.1字）** と、落ち着いて読み上げられる **ゆったり版（空白除き779字・4.45字/秒＝毎分267.1字）** の2通りを各 Step に併記しています。
- 録画する人も見る人も、`http://127.0.0.1:8000/` のガイドツアー `#tour=1`〜`#tour=5` に沿って同じ画面をたどれます。
- ツアーの番号と動画の Step の順番は一部異なります。動画では、ツアー③（原文根拠と推測拒否）を Step 2、ツアー②（空欄の自動発見）を
  Step 3 で見せます。

> 画面に出る様式・メモ・人名・団体名は、すべて本ハッカソン期間中にゼロから自作した架空のもの（医療以外の一般事務・研究事務・
> 自治体手続き）です。Form-Guard が機械的に確かめるのは「様式そのものが変わっていないこと」と「各値がメモの原文に紐づくこと」で、
> メモの内容が事実かどうかの確認と提出の判断は人が行います。
