### 3-1. Claude デスクトップアプリ（Claude Desktop）に MCP を繋ぐ設定
- 上記の `setup_remote_demo.ps1` を実行すると、`%APPDATA%\Claude\claude_desktop_config.json` に以下の設定が自動で書き込まれます。

```json
{

      "command": "C:\\hackathon\\form-guard-agent\\.venv\\Scripts\\python.exe",
      "args": ["-m", "form_guard.mcp_server"],
```

- **確認方法**：Claude Desktop を再起動すると、チャット入力欄のツールアイコンに次の5ツールが表示されます。
  1. `form_guard_list_demos`（デモ様式一覧）
  2. `form_guard_scan`（様式の欄・ルール読み取り）
  3. `form_guard_discover_blank_cells`（白紙様式の空欄4段階自動発見＆事務局欄ロック）

## 4. 【核心】デモ動画で審査員を唸らせる「5重の Guardrails（安全機構）」ベスト実演設計

プレゼン（スライド説明）ではなく **「実際に Claude アプリ／Claude Code の画面で Guardrails が働いているライブ映像」** として最も映えるのは、次の **5つの Guardrails が順番に画面上で発動する瞬間** です。

| 順序 | Guardrail（安全機構） | 画面上で何が起きるか（審査員への見せ場） | 対応するツール・仕組み |
|---|---|---|---|
| **①** | **白紙原本の改変阻止フック** | AIやコマンドが白紙様式（`samples/blank_forms/*`）を直接上書きしようとすると、書き込み前に `deny` で自動ブロック | `.claude/settings.json` (`PreToolUse` / `scripts/hook_guard.py`) |
| **②** | **4段階空欄発見＆事務局欄ロック** | マーカー無しの白紙Word/Excelから空欄を自動検出し、「申請者が書く7欄（✓）」と「総務部・事務局の2欄（[LOCK] 記入禁止）」に自動仕分け。Excelの `=SUM()` 数式セルも自動除外 | MCP `form_guard_discover_blank_cells` |
| **③** | **原文根拠・上限自己修正・推測ゼロ** | 用務内容を上限100字以内（59字）に整形、西暦を和暦「令和8年」に正規化。上限超過（デモ2：上限100万円に対し161万2千円）は自動差し戻しで100万円に再抽出。メモに無い法人番号は捏造せず `needs_human_input` で停止 | MCP `form_guard_fill` ＋ 3階層モデル（Haiku / Sonnet / Opus 5.5） |
| **④** | **7区分・21項目検査＆視覚ずれ 0 px** | 指定欄のバイト範囲だけを書き換え、未変更ZIPパーツは生バイト保持。罫線・結合セル・定型文・欄外の描画ずれ `0 px` を `21/21 PASS` で即時証明 | MCP `form_guard_verify` (`VIS-01`) |
| **⑤** | **代理承認の禁止＆人間承認ゲート** | MCPには「承認ツール」が存在せず、AIが出せるのは未承認下書き（`UNAPPROVED_DRAFT_REQUIRES_HUMAN_SIGN_OFF`）と確認URLのみ。ブラウザで人が白紙と並べて確認し、氏名を入れて承認した瞬間に初めてダウンロードが解錠 | Web UI (`http://127.0.0.1:8000/start?run_id=...`) |

### 🎬 ターン3：出力された `start_url` を開き、右画面のブラウザで Guardrail ⑤（視覚比較＆人間承認ロック解除）を実演する

## 7. 録画前のチェックリスト（事故ゼロ・減点ゼロのために）

- [ ] **個人情報・個人パスが映っていないか**：ターミナルのプロンプトは `C:\hackathon\form-guard-agent>` に固定されているか、ブラウザのブックマークバーや個人アカウントアイコンは隠れているか。
