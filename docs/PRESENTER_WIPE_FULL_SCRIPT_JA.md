## 🎙️ 2通りの使い方（① 手元でPowerPointをクリックして録画 ／ ② 175秒ミニシアター動画に合わせてワイプ録画）

### 方法A：PowerPoint（`FormGuard_Agent_ClickStep_Pitch_Deck_16x9.pptx`）を開いて、手元でクリックしながら話す場合
- 各スライドは `→`（またはクリック）を押すたびに、**赤枠コールアウト → カード① → カード② → 下部まとめバナー** の順に段階表示されます（4・7・8・13枚目は5回、ほかは4回で**全14枚合計60回の段階表示**。13枚目はカード3枚 → 赤枠 → まとめの順）。
- 各スライドの要素が全部出たあとにもう1回押すと次のスライドへ進みます（スライド送り13回を含め、最後のスライドが全部出るまで**計73操作**）。セリフを読みながら2〜3秒ごとに押すのが目安です。手動操作の収録時間（175秒は目標値）は一度通しで録って実測してください（※下部フルテロップと右下ワイプ枠は動画版 `FormGuard_Agent_Presenter_Wipe_Demo_175s.mp4` に焼き込まれており、PPTXでは発表者ノートに全文が入っています）。

### 方法B：自動進行の175秒ミニシアター動画（`FormGuard_Agent_Presenter_Wipe_Demo_175s.mp4`）を見ながら話し、右下ワイプに合成する場合
- **段階表示の自動再現**: 175秒動画版（`FormGuard_Agent_Presenter_Wipe_Demo_175s.mp4` および `FormGuard_Agent_Clean_Slide_Deck_175s.mp4`）にも、**全14枚・60段階のクリック表示（計74状態）**がそのまま収録されているため、ガイド動画を流しながら下部フルテロップを読むだけで画面内の赤枠やカードが順番に出現します。
- **カメラの向き（必須）**: 📱 **スマホ（iPhone等）は「横向き（16:9）」に固定して撮影してください**（縦撮りだと左右を大きく拡大トリミングすることになり顔が切れる原因になります）。胸から上のバストアップ、目線は正面カメラ。
- **HDRビデオ設定（iPhoneの場合）**: 「設定 → カメラ → ビデオ撮影」の **「HDRビデオ」をオフ（SDR）** にして撮影してください（HDRオンだとSDR合成時に肌や背景が白飛びする恐れがあります）。
- **進行に合わせた録画手順（0:00クラップ同期）**:
  1. PC画面でガイド動画 `C:/hackathon/demo_video_output/FormGuard_Agent_Presenter_Wipe_Demo_175s.mp4` を開く（PCスピーカー音量はゼロまたはイヤホンにしてカメラにPC音が入らないようにする）。
  2. スマホのカメラ録画を開始する。
  3. PCのガイド動画を再生開始した**ちょうど `0:00` の瞬間に「パチン」と1回だけ手を叩き（クラップ合図）**、画面下部のフルテロップ（`01 / 14`〜`14 / 14`）を読み上げながら `2:55`（175秒）まで話す。
- **動画ファイル配置**: 撮影した動画（`.mp4` または `.mov`、**音声トラック入り・実尺は `175.00秒 ＋ --offset 秒数` 以上［例：`--offset 1.5` なら `176.50秒` 以上］必須**）を `C:/hackathon/demo_video_output/presenter_camera.mp4` に配置。
- **自動マージコマンド**:
  ```powershell
  python -X utf8 C:/hackathon/demo_video_output/scripts/merge_camera_into_wipe.py --offset 1.5
  ```
  ※ `--offset` には、カメラ録画開始から手を叩いた瞬間（ガイド動画 `0:00`）までの秒数を指定します（映像・音声の両方に同時適用され、通常時は offset 適用後の映像・音声ストリーム両方が 175.00秒以上あることを機械検査します）。出力先に既存ファイルがある場合は自動で `.bak` に退避したうえで `C:/hackathon/demo_video_output/FormGuard_Agent_FINAL_Presenter_Demo_175s.mp4` が生成されます。
