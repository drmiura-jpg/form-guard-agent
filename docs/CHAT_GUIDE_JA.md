# Claude にチャットで頼む（Form-Guard おまかせ記入ガイド）

Web 画面の操作をしなくても、Claude Code に日本語で頼むだけで「空欄探し → 記入 → 自己チェック」まで AI が進めます。
人がするのは2つです。

1. 目印のない様式・PDF では、Claude が見せる記入欄の候補に「おすすめの欄で」などと答える（事務局が書く欄は選べません）。
2. 最後にかんたん画面で **確認項目にチェックして承認する**。

## 準備（最初の1回）

1. このリポジトリのフォルダで Claude Code を起動します（`.mcp.json` の `form-guard` MCP サーバーが自動で読み込まれます）。
2. 別の窓で Web 画面を起動しておきます: `python -m form_guard.cli --serve`（http://127.0.0.1:8000）
3. 初回は Claude Code が MCP サーバー `form-guard` の使用許可を聞くので、許可してください。

> ⚠️ チャットに貼った文章は Claude（Anthropic）に送られます。患者さんの情報・個人情報・未公開の資料は貼らず、架空の内容で試してください。

## 頼み方（例）

| やりたいこと | Claude への頼み方 |
|---|---|
| 公募ポータルの様式を使う | 「公募ポータルから研究会のPDF様式をダウンロードして、`samples/memos/memo6_study_group_grant.txt` の内容で埋めて確認画面を開いて」 |
| 手元の様式を使う | 「`output/my_form.docx` を、このメールの内容で埋めて確認画面を開いて」＋メール本文を貼る |
| 結果だけ知りたい | 「さっきの下書き、入力待ちの欄はある？」 |

## Claude が裏でやること

1. `form_guard_discover_blank_cells` — 白紙の様式から記入欄を探し、事務局欄（🔒）を除外します。
2. 見つけた候補をあなたに見せ、記入する欄を選んでもらいます。
3. `form_guard_fill` — 材料にある内容だけを、選んだ欄だけに書きます（材料にない欄は推測せず空欄のまま）。
4. `form_guard_verify` — 指定欄以外が変わっていないかを機械で検査します。
5. リンクを2つ返します: かんたん画面 `start_url`（`/start?run_id=…`）と、詳しい画面 `review_url`（`/?run_id=…`）。

## 最後に人がすること

Claude が返した `start_url`（かんたん画面）を開きます:

```
http://127.0.0.1:8000/start?run_id=<run_id>
```

- 入力待ちの欄が無ければ、いきなり STEP 5（人の最終確認）が開きます。確認項目を1つずつチェックし、名前を入れて承認するとダウンロードできます。
- 入力待ちの欄があれば STEP 4 が開くので、値を入れて「反映して再検査」を押してから進みます。
- Claude は承認ボタンを押しません（承認は必ず人が行います）。

> 一時公開URL（`scripts/share_tunnel.ps1`）で開く場合は、表示された `…/start?key=…` を一度開いてから `…/start?run_id=<run_id>` を開いてください。公開中は架空のサンプル様式だけを使ってください。
